# PO(DI)NG

https://www.youtube.com/watch?v=BFxndyX0GhM

pong in odin + raylib

## run

install odin, then:

```sh
odin run .
```

W / S for the left paddle, up / down for the right.
space to start and serve after a point. first to 7 wins.
space again to play another game, esc to quit.

```sh
odin test .
```
